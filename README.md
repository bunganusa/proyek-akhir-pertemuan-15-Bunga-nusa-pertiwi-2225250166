# Proyek Analisis Nilai Siswa

## Deskripsi
Aplikasi ini dikembangkan untuk membantu pengolahan data nilai siswa secara otomatis. Program dapat menerima input nilai, menghitung statistik dasar (rata-rata, nilai minimum, dan nilai maksimum), menentukan status kelulusan siswa berdasarkan batas nilai tertentu, serta menyimpannya ke file teks

## Fitur
- **Input Interaktif**: Memasukkan data nilai langsung melalui console terminal dengan validasi input invalid
- **Impor Data**: Membaca data nilai secara otomatis dari file teks (`data/nilai_siswa.txt`)
- **Analisis Statistik**: Menghitung rata-rata, mencari nilai tertinggi/terendah, dan menentukan kelulusan.
- **Ekspor Ringkasan**: Menyimpan hasil analisis ke file teks `data/hasil_analisis.txt`.

## Persyaratan
- Python 3.x
- VS Code (disarankan untuk running dan debugging)
